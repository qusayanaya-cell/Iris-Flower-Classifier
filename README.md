# Iris Flower Classifier

A machine learning model that predicts the species of an iris flower
(Setosa, Versicolor, or Virginica) from four measurements: sepal length,
sepal width, petal length, and petal width.

## Details
- Algorithm: K-Nearest Neighbors (k=3)
- Library: scikit-learn
- Accuracy: 93.3%
- The trained model is saved with joblib (mlbrain.joblib)

## How to run
1. Install the requirements: pip install scikit-learn joblib
2. Open Iris_flower.ipynb in Jupyter and run all cells
